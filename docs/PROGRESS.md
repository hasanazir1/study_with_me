# التقدّم الحالي — سَكَن

آخر تحديث: 2026-11-16.

## ابدأ من هنا

تطبيق Android APK، Java Activity + WebView عادي. الحزمة `com.sakin.study`، النسخة **1.2.0 / versionCode 3**، بالتوقيع الأصلي نفسه. المرحلة الثانية منفّذة وبانتظار تجربة APK الجديد وملاحظات المستخدم. لا تبدأ المرحلة الثالثة حتى يطلبها.

جرّب المستخدم المرحلة الأولى وأبلغ عن حركة ضعيفة، أصوات عالية ومتشابهة، غياب نغمة نهاية مسموعة، والحاجة إلى بدء الراحة تلقائيًا. النسخة الحالية تعالج هذه الملاحظات وتنفّذ محرك الصوت للمرحلة الثانية.

## ما تغيّر

- سبع طبقات ستيريو مدتها 60 ثانية، بدل حلقات 24 ثانية أحادية القناة: مطر وزجاج وبحر وجدول بتسجيلات CC0، وهواء وضجيج بني وفقاعات مولّدة. المصادر والنسخ المضغوطة المستعملة وبصماتها موضحة في [AUDIO.md](AUDIO.md)، والاعتماد ظاهر داخل التطبيق.
- مسار AudioTrack أصلي واحد، ومزج PCM دون فاصل ملف عند التكرار، وتحميل عند الطلب، وتحكم مستقل لكل طبقة وبالصوت العام، وfade مدته 1.2 ثانية. مستوى الإعداد المحفوظ يبقى، والمزيج الجديد أخفض قليلًا.
- خدمة mediaPlayback أمامية وMediaSession بإشعار تشغيل/إيقاف/إغلاق، ومعالجة audio focus وفصل السماعات وقفل CPU أثناء التشغيل فقط. مؤقّت نوم يوقف الصوت دون المؤقّت.
- نغمة نهاية من نغمتين، للتركيز والراحة، مع معاينة وخيار تعطيل. تستخدم قناة تنبيه جديدة بصوت مورد محلي؛ الصوت يتبع إعدادات تنبيهات أندرويد والصامت وعدم الإزعاج. عند رفض إذن التنبيهات والتطبيق ظاهر، يوجد تشغيل أصلي قصير بديل.
- بعد التركيز يبدأ عدّ 5 ثوانٍ ثم الراحة تلقائيًا؛ يمكن الإلغاء أو تعطيل السلوك. الدراسة التالية تبدأ يدويًا. الجلسة قبل الصلاة لا تضع راحة مؤجلة؛ التوقف للصلاة والإعادة وإعادة تشغيل الهاتف تمنع انتقالًا غير مرغوب.
- قفل الاتجاه يبقى مستقرًا عبر الخمس ثواني والانتقال للراحة. عند وصول منبّه النهاية في الخلفية تستخدم نافذة receiver قصيرة مع قفل CPU محدود، لتفادي الاعتماد على منبّه idle ثانٍ بعد خمس ثوانٍ. المواعيد المخزنة تعوّض تأخر الرجوع إلى التطبيق.
- حركة أرقام وصفحات ألطف، تنفس خفيف للحلقة والورقة، ومؤشر دوران عبر transform. أُزيل التمويه المتراكم ولقطات View Transition عند تدوير الـ Activity. الحركة تتوقف عند إخفاء الواجهة وتحترم تقليل الحركة.
- الأزرار الخافتة تعمل من أول ضغطة بدل ابتلاع الضغطة الأولى. بقي المؤقّت والمدد والإعادة والصلاة ومواقيت اليوم والمدينة و«صليت» و«جلسة قبل الصلاة» والسجل والإعدادات العربية.

## ما تم فحصه لهذا الإصدار

- اختبارات Java للمؤقّت والصلاة السابقة، واختبارات الراحة الجديدة: المهلة، الإلغاء، البدء اليدوي، عدم تكرار الانتقال، الرجوع المتأخر، إعادة التشغيل، واستثناء الجلسة قبل الصلاة.
- فحص مزج عينات PCM: قناتا الستيريو، التفاف الحلقة دون عينة صمت مضافة، fade إلى الصمت، والتبديل السريع وإخلاء الطبقات السابقة. فُتحت الملفات الفعلية بقارئ Java المستخدم في التطبيق.
- سلامة الأصول: سبعة ملفات مختلفة، 60 ثانية ستيريو، بصمات صحيحة، لا قص رقمي، حدود حلقات طبيعية، وهامش للمزيج حتى مع كل منزلقاته عند 100%.
- فحص JavaScript وربط 91 مرجع واجهة وعدم تكرار معرّفات العناصر.
- نفس الواجهة الفعلية في متصفح محلي بجسر اختباري، بمقاسات 320×568 و396×806 و784×388 و1151×791: دون تمرير رئيسي أو قص الأزرار، مع الصلاة، اختيار الأصوات والطبقات، مؤقّت الصوت، الهدوء، الراحة التلقائية وإلغائها، أول لمسة بعد الخفوت، الداكن وتقليل الحركة. لا أخطاء JavaScript في هذا الفحص.
- بناء APK، توقيع v2/v3 ومحاذاة صحيحة، تطابق شهادة التوقيع مع APK السابق، نفس الحزمة ورقم نسخة أعلى. كل الأصوات والخط والاعتماد والنغمة داخل الملف؛ لا صلاحية إنترنت ولا كود المعاينة أو مفتاح توقيع ضمن APK.

## ما لم يُتحقق منه بعد

**APK 1.2.0 لم يُجرّب هنا على أندرويد فعلي أو محاكي.** فحص المتصفح لا يشغّل الخدمة أو AudioTrack أو واجهات التدوير. جودة السماع على سماعات الجوال، استمرار الصوت والشاشة مطفأة، إشعار الوسائط، المكالمات والبلوتوث، سلاسة التدوير والنوتش والأذونات تحتاج تجربة المستخدم. لا تُقدّم نجاح البناء كدليل على هذه الحالات.

تسجيلات البحر والجدول جاءت من نسخ المعاينة MP3 المتاحة، وليست التسجيلات الأصلية بلا فقدان. التحويل إلى PCM لا يستعيد التفاصيل المفقودة. موازنة المستويات RMS وليست مطابقة إدراكية كاملة لـ LUFS. اختيرت المعالجة والمحرك لتحسين التجربة مع مصادر موثقة، ويبقى السماع الفعلي شرط تقييم الجودة.

إذن التوقيت الدقيق وإذن التنبيهات منفصلان. بدون الأول قد يتأخر وصول نهاية الجلسة أصلًا بالخلفية؛ وبعد وصولها تُمنح خمس ثوانٍ قبل الراحة. force-stop وقيود البطارية وقتل الخدمة يمكن أن توقف العمل. راجع [قائمة تجربة النسخة](PHASE2_TEST_AR.md).

## الباقي من الخطة

المرحلة الثالثة للمشاهد، والرابعة للشخصية، والخامسة لتنبيه الصلاة الجديد قبل عشر دقائق والسلوك الجديد والتلميع. هذه لم تبدأ. التنبيه السابق بخمس دقائق ومزايا الصلاة الأصلية محفوظة. الحقول البصرية وحالة الشخصية في `scenes.json` تجهيز للمرحلة القادمة، وليست تأثيرات منفّذة.

التعديلات محفوظة في فرع `feat/phase-2-audio`؛ الإصدار `v1.2.0` يحدد المصدر الموافق للـ APK. عند تسليم المشروع لـ AI آخر، اطلب فتح الفرع أو العلامة الأحدث وقراءة AGENTS وهذا الملف وROADMAP وAUDIO. مفتاح التوقيع الخاص يبقى خارج Git.
