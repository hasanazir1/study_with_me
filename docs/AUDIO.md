# صوت سَكَن — المرحلة الثانية

لا تحتاج تنزّل أصوات أو تنقل ملفات للجوال. النسخة 1.2.0 تضم كل الملفات داخل APK وتعمل دون إنترنت. حجمها قرابة 54 MB لأن الحلقات مخزّنة PCM مباشرة دون ضغط صوتي إضافي عند التشغيل.

## المحرك ولماذا اخترناه

التطبيق Java + WebView عادي، وبناؤه الحالي مباشر دون Gradle. اختير **AudioTrack** الأصلي بدل إضافة Media3 لهذه المرحلة: تشغيل الطبقتين في مسار PCM واحد يتيح المزج والـ fade والتكرار على ساعة العينات نفسها، دون محاولة مزامنة مشغّلين منفصلين. هذا تشغيل أصلي بالكامل، وليس Web Audio داخل خدمة. [واجهة AudioTrack الرسمية](https://developer.android.com/reference/android/media/AudioTrack).

`PcmMixer` يمزج عينات ستيريو 32 kHz / 16-bit، ويغيّر المستوى تدريجيًا خلال 1.2 ثانية. عند نهاية الملف يعود مباشرة لأول عينة في المخزن نفسه، دون إغلاق المشغّل أو إعادة فتحه. الحلقات 60 ثانية، ونقطة التكرار مجهّزة بتداخل ناعم. طبقتان لكل اختيار، حجم عام، وتحكم مستقل محفوظ لكل طبقة. التحميل عند الطلب خارج خيط الواجهة، وتتحرر المصادر السابقة بعد الانتقال.

`SoundService` خدمة `mediaPlayback` أمامية بإشعار تشغيل/إيقاف وإغلاق، وMediaSession للأزرار وشاشة القفل. تطلب audio focus بعد بدء foreground، كما يتطلب أندرويد 15. تخفّض الصوت عند المقاطعة الخفيفة، وتتوقف عند فقد التركيز، وتستأنف بعد المقاطعة المؤقتة فقط ما لم يوقفها المستخدم. فصل السماعات يوقف الصوت. [قواعد audio focus](https://developer.android.com/media/optimize/audio-focus).

أثناء التشغيل تمسك الخدمة قفل CPU جزئيًا، منفصلًا عن إبقاء الشاشة صاحية. تحرره عند التوقف، وتوقف خيط المزج. الـ WebView يتوقف عن الحركة والتحديث حين يُخفى. مؤقّت النوم 15/30/60/90 دقيقة يوقف **الصوت فقط**؛ لا يوقف مؤقّت الدراسة. صوت نهاية الجلسة يتبع إعدادات التنبيهات في أندرويد، لا شريط صوت الأجواء.

المصادر المستعملة للتجهيز نسخ MP3؛ البحر والجدول من معاينات Freesound العامة، والمطر والزجاج من النسخ التي يقدمها [موقع المطر مع سجل مصدرها](https://rainsoundsforsleeping.com/licensing/). ليست WAV الأصلية بلا فقدان؛ تحويلها إلى PCM لا يستعيد تفاصيل الضغط المفقودة. عولجت لتخفيف الحدة والتغيّر المفاجئ في المستوى، وليس ادعاء إزالة كل عيب تسجيل. تقييم الراحة والجودة بالسماع على الجوال ما زال مطلوبًا.

كل ملف ستيريو مستقل، RMS قرابة ‎−13.15 dBFS، مع هامش قبل القص. كسب المحرك العام 0.86، ومستويات المزيج الافتراضية تجعل الأجواء أخفض قليلًا من النسخة السابقة عند إبقاء منزلق الصوت نفسه. إعداد الصوت المحفوظ عند المستخدم لا يُمسح. هذه موازنة RMS؛ ليست مطابقة إدراكية كاملة لـ LUFS بين الأصوات.

## إذا أردت إعادة تجهيز الملفات

البناء العادي يستخدم الملفات الجاهزة المحفوظة في Git. تحتاج Python وNumPy وSciPy وffmpeg لإعادة التجهيز فقط:

```text
python -m pip install numpy scipy
```

نزّل الروابط في `assets/audio/sources.json` بالأسماء التالية إلى مجلد تختاره، مثل `../audio-sources/`:

| اسم التنزيل المطلوب | الصيغة | رابط التنزيل |
| --- | --- | --- |
| `rain.mp3` | MP3 ستيريو | https://rainsoundsforsleeping.com/audio/rain-base.mp3 |
| `window.mp3` | MP3 ستيريو | https://rainsoundsforsleeping.com/audio/window.mp3 |
| `ocean.mp3` | MP3 ستيريو | https://cdn.freesound.org/previews/417/417797_3285887-hq.mp3 |
| `stream.mp3` | MP3 ستيريو | https://cdn.freesound.org/previews/457/457960_2841496-hq.mp3 |

```text
python tools/prepare_audio.py --sources ../audio-sources
python tests/check_audio.py
```

الأداة تجهّز الملفات النهائية بالأسماء والمسارات في الجدول الأول، ومعها النغمة وتقرير `analysis.json`. لا تعِد تسميتها إلى MP3 ولا تغيّر الصيغة بالاسم فقط. بدون `--sources` تتولد بدائل إجرائية؛ لا تحصل على التسجيلات الطبيعية نفسها. أي تغيير بالأصول يستلزم مراجعة الاعتماد والتقرير والاختبارات قبل التسليم.

## حدود التحقق والخلفية

نجحت اختبارات المزج الفعلي لعينات PCM: قناتا الستيريو، الانتقال الدقيق عند نقطة التكرار، fade إلى الصمت، تبديل المصادر وإخلاؤها. وفحوص الأصول تؤكد اختلاف الملفات، طولها، التوقيعات، عدم القص، سلامة حدود الحلقات، وهامش المزيج عند أعلى منزلقات.

**لم تتوفر تجربة جهاز أندرويد أو محاكي لهذا الإصدار.** بُني APK وفُحص توقيعه؛ معاينة المتصفح لا تشغّل AudioTrack أو خدمة أندرويد. استمرار الصوت والشاشة مطفأة، أزرار الإشعار، المكالمات والبلوتوث بحاجة قائمة تجربة الجوال. النظام قد يوقف التطبيق عند force-stop أو قتل الخدمة أو قيود الشركة المصنّعة؛ لا توجد دعوى ضمان تشغيل مطلق.

صلاحيات الخدمة والـ wake lock موجودة. أندرويد 13+ يطلب إذن التنبيهات، وهو لازم لتنبيهات المؤقّت العادية؛ إشعارات جلسات الوسائط لها استثناءات نظامية. رفض الإذن لا يعني أن AudioTrack يحتاج إنترنت أو صفحة مفتوحة. [إذن التنبيهات الرسمي](https://developer.android.com/develop/ui/views/notifications/notification-permission).
