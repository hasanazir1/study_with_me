# الخطة المتفق عليها

المنتج غرفة دراسة صغيرة هادئة ودافئة، تعمل كتطبيق أندرويد مستقل دون حساب أو اتصال بالإنترنت. المؤقت هو العنصر البصري الأساسي، مع الصلاة القادمة والأصوات وأدوات سريعة على شاشة واحدة.

## ١. التصميم والتجربة الأصلية — منجزة، بانتظار تجربة الجوال

- فاتح كريمي افتراضي، وداكن أزرق أخضر ناعم.
- أخضر مريمية للتركيز ورملي للصلاة والراحة، وخط عربي محلي.
- حلقة تقدم، أرقام متحركة بخفة، أزرار pills وsheets للتفاصيل.
- شاشة رئيسية واحدة بالطول والعرض، وتخفيف الأزرار أثناء الجلسة.
- immersive وActivity orientation وsafe insets وFLAG_KEEP_SCREEN_ON أثناء الجلسة، مع haptics أصلية.
- إبقاء جميع وظائف النسخة الأصلية.

## ٢. محرك الصوت — منفّذ في 1.2.0، بانتظار تجربة الجوال

- تشغيل أصلي مستقل عن الـ WebView؛ المحرك المختار AudioTrack PCM لمسار واحد متعدد الطبقات؛ الأسباب والحدود في AUDIO.md.
- foreground service من نوع mediaPlayback وMediaSession وإشعار تحكم، وإذن الإشعارات من أندرويد ١٣.
- حلقات ستيريو هادئة مدتها 60–180 ثانية، بلا فجوات أو طقطقة، ومستويات صوت متقاربة.
- ملفات مرخصة مع اعتماد داخل التطبيق عند الحاجة؛ CC0 مفضّل، وبديل مولّد نظيف إن لم تتوفر جودة كافية.
- طبقات لكل مشهد، تحكم بكل طبقة وبالصوت العام، fade ناعم ومؤقت نوم اختياري.
- كل الأصول داخل APK، مع اختبار إطفاء الشاشة والخلفية على جهاز فعلي.

أُضيفت أيضًا ملاحظات التجربة: نغمة نهاية، راحة تلقائية بعد 5 ثوانٍ قابلة للإلغاء، وتحسين الحركة. لا تبدأ الدراسة التالية تلقائيًا. لم يُنفّذ اختبار جهاز فعلي لهذا الإصدار؛ هذا شرط قبول تجريبي باقٍ وليس ادعاء اكتمال التحقق.

## ٣. المشاهد والتأثيرات — نسخة أولية 1.3.0 للتجربة

نُفذت غرفة SVG بسيطة بستة أجواء، وإعداد واحد لكل جو في room.js يحدد الألوان والمؤثر ومرجع صوت اختياري وحالة الشخصية المستقبلية. الصوت مستقل في هذه النسخة الأولية. التفاصيل قابلة للتحسين بعد تجربة الجوال:

- مطر: نافذة وقطرات وضباب خفيف وبرق نادر خافت.
- طبيعة: أوراق وضوء ويراعات.
- مدفأة: وهج دافئ وشرر قليل.
- مقهى: بخار وbokeh دافئ.
- ليل: نجوم وقمر.
- هدوء: دون صوت.

تبديل ناعم، وحركات خفيفة عبر transform/opacity وCanvas بحد أقصى 60fps، وإيقاف المؤثرات عند إخفاء التطبيق. تقليل الحركة والجزيئات وخيار «حركة أخف» مطلوبان.

## ٤. الشخصية — لم تبدأ

- شخصية غير بشرية تناسب هوية الورقة، منفصلة عن منطق المؤقت.
- دخول وترحيب، وقوف وتنفس ورمش، مشي إلى المكتب، جلوس للدراسة، تمدد بالراحة، احتفال بالنهاية، وهدوء قرب الأذان.
- واجهة مثل `setState('walk')` تسمح باستبدال SVG/CSS لاحقًا بـ Rive أو dotLottie.
- زر إخفاء للشخصية ووضع تركيز بحت.

## ٥. الصلاة والأوفلاين والتلميع — لم تبدأ

- تنبيه لطيف قبل الأذان بعشر دقائق: «قرّب الأذان، نكمل ولا نوقف؟».
- إيقاف المؤقت وتهدئة المشهد عند الأذان كخيار.
- اقتراح مدة مناسبة لجلسة قبل الصلاة، مع حساب وطريقة ومذهب وتعديلات يدوية محفوظة.
- إشعارات أندرويد محلية، وشرح أذونات التوقيت الدقيق وحدود النظام والبطارية.
- التحقق من بقاء كل الملفات محلية وتحميل الأصوات عند الحاجة، واختبار الأداء والبطارية والدقة والخلفية.
- الحفاظ على الحزمة وشهادة التوقيع ورفع versionCode لكل APK مسلّم.

نتوقف بعد كل مرحلة للملاحظات، ونحفظ نتيجتها في Git وCHANGELOG وملف التقدم. لا يوجد جزء PWA أو خدمة ويب في الخطة الحالية.
