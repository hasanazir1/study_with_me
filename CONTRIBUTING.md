# Contributing

Read [AGENTS.md](AGENTS.md), [current progress](docs/PROGRESS.md) and the [development guide](docs/DEVELOPMENT.md) first.

- Keep changes focused and preserve the Android/RTL/offline constraints.
- Use a branch and describe the problem and resulting behavior in a pull request.
- Run the relevant checks and explain what was actually tested on Android.
- Update progress and changelog when behavior or milestone status changes.
- Never include private keys, credentials, personal device data or generated APK/build files in a commit.
- Do not begin an unapproved later phase or change package/signing identity.

Issues and pull requests can propose improvements. The owner decides the next phase and official APK release.
